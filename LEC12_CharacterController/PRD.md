# 캐릭터 상태 및 자동 달리기 기능 PRD

## 1. 문서 개요

- **제품/기능:** 2D 캐릭터 상태 및 자동 달리기
- **대상 프로젝트:** `Labs/LEC12_CharacterController`
- **목표 사용자:** 방향키와 단축키로 캐릭터 애니메이션을 확인하는 플레이어
- **상태 다이어그램:** [state_diagram.svg](./state_diagram.svg)

## 2. 배경과 목표

캐릭터의 대기, 수동 달리기, 자동 달리기 상태를 명확히 분리한다. 플레이어는 방향키로 캐릭터를 조작하거나 `A` 키로 자동 달리기를 시작할 수 있다. 자동 달리기 중에는 속도와 크기가 눈에 띄게 증가하지만, 캐릭터의 발은 잔디 높이에 고정되어야 한다.

### 목표

1. IDLE, RUN, AUTORUN 상태를 구현하고 상태에 맞는 애니메이션을 표시한다.
2. 수동 RUN은 방향키 입력에 따라 움직이고, 입력 해제 시 IDLE로 복귀한다.
3. AUTORUN은 방향키 조작 없이 자동으로 왕복 이동하고, 시간이 지날수록 빨라지고 커진다.
4. 자동 달리기 중에도 캐릭터가 화면과 잔디 위에 유지되도록 한다.

### 범위 밖

- SLEEP 상태 및 Space 키 동작
- 점프, 공격, 생명력, 적, 충돌 판정, 피해 처리
- 자동 달리기 종료 후 기록이나 점수 처리

## 3. 사용자 입력

| 입력 | 동작 |
|---|---|
| 왼쪽 방향키 누름 | IDLE에서 왼쪽을 향한 RUN 시작 |
| 오른쪽 방향키 누름 | IDLE에서 오른쪽을 향한 RUN 시작 |
| 방향키 해제 | RUN에서 IDLE로 복귀 |
| `A` | IDLE에서 AUTORUN 시작 |
| AUTORUN 중 방향키 | AUTORUN을 취소하고 해당 방향의 수동 RUN으로 전환 |
| `Esc` | 게임 종료 |

방향키를 양쪽 모두 누른 경우 마지막으로 눌린 방향을 우선한다. 방향키가 하나라도 눌려 있는 동안에는 RUN을 유지한다.

## 4. 상태 및 전이 요구사항

### IDLE

- 시작 상태이며, 대기 애니메이션을 반복 재생한다.
- IDLE에서 5초가 지나도 다른 상태로 자동 전환하지 않는다. 계속 IDLE 상태를 유지한다.
- 왼쪽 또는 오른쪽 방향키 입력은 RUN으로 전환한다.
- `A` 입력은 AUTORUN으로 전환한다.

### RUN

- 수동 입력 방향으로 이동하며 달리기 애니메이션을 재생한다.
- 방향키가 모두 해제되면 IDLE로 돌아간다.
- 캐릭터가 화면 밖으로 나가지 않도록 위치를 제한한다.

### AUTORUN

- `A` 입력으로 IDLE에서 진입한다.
- 시작 방향으로 자동 이동하며, 좌우 화면 끝에 도달하면 방향을 반전한다.
- 진입 시점부터 5초간 유지한 다음 IDLE로 복귀한다.
- 진행 시간에 따라 속도와 크기를 키운다.
- 방향키 입력이 들어오면 즉시 AUTORUN을 취소하고, 입력 방향으로 수동 RUN에 진입한다.
- 취소 또는 정상 종료 시 크기를 기본 크기로 되돌린다.
- 확대 중에도 캐릭터의 실제 발 위치를 잔디 표면 높이에 고정한다.
- **무적 의미:** AUTORUN 중에는 피해를 받지 않아야 한다. 현재 프로젝트에는 충돌·피해 시스템이 없으므로, 해당 시스템이 추가되면 AUTORUN 상태 동안 피해 판정이 적용되지 않는지 별도로 검증해야 한다.

상태 전이의 시각화는 [상태 다이어그램](./state_diagram.svg)을 기준으로 한다.

## 5. 현재 자동 달리기 튜닝값

아래 값은 현재 구현의 기본 파라미터이며, 게임 밸런싱에 따라 조정할 수 있다.

| 항목 | 현재 값 |
|---|---:|
| 지속 시간 | 5초 |
| 시작 속도 | 초당 100 픽셀 |
| 가속도 | 초당 초당 140 픽셀 |
| 최대 속도 | 초당 700 픽셀 |
| 크기 증가율 | 초당 0.6배 |
| 최대 크기 | 기본 크기의 4배 |

## 6. 화면 및 애니메이션 요구사항

- 캐릭터는 좌우 방향에 맞는 RUN 스프라이트 행을 사용한다.
- AUTORUN의 확대는 스프라이트를 비례 확대한다.
- 스프라이트 투명 여백이 아닌 실제 발의 기준점이 확대 비율에 관계없이 잔디 표면에 맞아야 한다.
- 캐릭터의 전체 표시 영역이 좌우 화면 경계를 벗어나지 않도록 크기를 고려해 이동 범위를 계산한다.
- 화면 해상도와 잔디 높이에 맞춰 발 고정 기준을 검증한다.
